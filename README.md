报告覆盖东财半导体板块 185 家上市公司的产业链分类与定量筛选，对短名单五家（澜起科技、北方华创、兆易创新、紫光国微、盛美上海）完成 6.1–6.16 全步骤分析，并对综合得分第一的澜起科技完成 7.1–7.15 回撤防御分析。

核心结论（研究观点，非投资建议）：质量上首选澜起科技；2026-08-12 现价约 213.8 元、动态 PE 约 77 倍，不具备安全边际，建议观察而非买入。
