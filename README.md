### 技术说明

- 单文件 HTML，零外部依赖（无 CDN、无字体加载），自定义 SVG 图表引擎 + 原生 JS 渲染；
- 支持按赛道筛选、悬停提示、滚动导航、返回顶部、打印优化（Ctrl/Cmd + P）；
- 所有财务数据为公开报道与第三方估计口径（截至 2026.9），不构成投资建议。
